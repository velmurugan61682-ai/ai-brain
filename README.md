# PocketPal Web

A React, TypeScript, and Vite web interface for PocketPal AI, with browser-side WebLLM support.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/` — React application source
- `public/` — static public assets
- `assets/`, `android/`, and `ios/` — PocketPal resources and native app project files

## Main libraries

- React 19
- TypeScript
- Vite
- WebLLM (`@mlc-ai/web-llm`)

This repository is based on the PocketPal AI project. Use the Vite scripts above to run the web application.
